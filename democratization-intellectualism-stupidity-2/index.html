国家運営は民主的であるほど良いか？知性主義者の見解、または如何にして阿呆共鳴現象を叩き潰すか（中編）
2024-12-09
Uncategorized
タグなし

前記事では、新自由主義・無料広告モデル・SNSの組み合わせが阿呆共鳴現象を産み、政治的アジェンダを民衆に委ねすぎることでファシズムに陥り自滅する可能性を指摘した。
これを回避するには、新自由主義と阿呆共鳴プラットフォーム（無料広告モデル＋SNS）の双方を抑制する必要がある。
本記事では、まず新自由主義を抑止する方法について論じる。

国家権力の強化による新自由主義への歯止め#

阿呆共鳴現象の原因の一つは新自由主義である。すなわち、社会の趨勢を市場に委ね放置するレッセ・フェールの思想がそれを可能にしている。これを止めるには、資本の論理に歯止めをかける別種の社会構造をねじ込む必要がある。

歴史上、これを唯一実現し得た存在が国家である。国家は暴力装置を独占しており、資本的腐敗に侵されていない暴力は資本より強い。オリガルヒに支配されていた90年代ロシアを、プーチンが暴力によって制圧した事例が端的な証左である。

もちろん、プーチンのような専制手法を肯定するものではない。だが、立法と文民統制の効いた軍や警察（＝暴力装置）を用いた行政により、新自由主義の進展を反転させることは可能である。

新自由主義を抑える方法#

新自由主義を止めるには、それを推進する勢力と手法を把握する必要がある。ここでは最も分かりやすい例として米国を取り上げる。

米国における新自由主義の推進勢力は、超富裕層である。彼らは企業、政治団体、ロビイスト、買収したメディア等を通じて政治過程に影響を与える。その思想的・文化的背景は多様であるが、最終的には「さらなる富の蓄積」に収束する。

超富裕層の政治的行動は、PESTの観点から次のように整理できる：

  • 経済的要因 → 蓄財効率の強化（減税・規制撤廃・民営化の推進）
  • 政治的要因 → 政治的影響力の強化（政治献金依存の政治制度維持）
  • 社会的要因 → 文化的権威の強化（金銭的成功の絶対視）
  • 技術的要因 → 技術資本の強化（上記すべてを効率化する資本独占）

従って、これに対抗するには以下が必要である：

  • 経済的要因 → 蓄財効率の低下（増税、規制強化、公営化）
  • 政治的要因 → 政治的影響力の抑制（政治献金の制限または禁止）
  • 社会的要因 → 文化的権威の衰退（教育/公共財無償化を通じた高信頼社会の醸成）
  • 技術的要因 → 技術資本の分散（競争政策による資本集積の排除）

各要因への具体的対応#

再分配率の増加

まず、超富裕層への権力集中を抑える最も直接的な方法は、富の再分配率の増加である。金融所得課税の強化、国家インフラ（特にメディア）の私物化防止、公共財に関わる企業の公営化などが挙げられる。
これにより資本効率は一時的に低下するが、高信頼社会が形成されれば私的資産に対する需要は減退し（所有しなくても幸福に生きられる）、社会厚生関数はむしろ増大する。

企業金銭の排除

次に、政治過程に対する金銭の影響を排除することが重要である。米国の大統領選では数千億円が必要とされ、小口献金が全体の2割に過ぎないため、超富裕層の意向が政治に及ぶ影響は無視できない。
実際、民主党の大口献金者リード・ホフマンが、反トラスト政策を進めるリナ・カーンの更迭を要求した例がある。
このような介入を防ぐためには、政治献金の制限または禁止が不可欠である。

拝金主義の是正

また、米国社会に蔓延する拝金主義を排除し、高信頼社会を再構築する必要がある。米国の子供向けコンテンツでは、ヒーローの多くが富裕層である。アイアンマン、バットマン、プロフェッサーXなど、金銭的成功がヒーロー像に強く結びついている。
一方、日本の国民的コンテンツでは、大金持ちの主人公は極めて稀である。金儲けは悪役の動機とされ、思想犯が悪の象徴とされることも多い。
文化は構造的に形成されるもので逆転は容易ではないが、20世紀中頃の米国が高福祉国家であったことに鑑みれば、不可能ではない。
教育改革と公共サービスの無償提供を通じて、蓄財の文化的正当性を意図的に低下させていくべきである。

技術資本独占の排除

最後に、技術資本の独占に伴う腐敗を防ぐ必要がある。
その典型例が、イーロン・マスクによるTwitter買収と、政府効率化省長という公的ポストの獲得である。Twitterを利用してMDM（偽情報・誤情報・悪情報）を拡散し、トランプ勝利を支援した見返りとして、自社への補助金配分等の利益誘導が可能な地位を得た。
公益性の高い資本を一部の人間が独占すると、知財蓄積に公共財を流用する危険が増大する。
現連邦取引委員会長のリナ・カーンは、GoogleのChrome事業分離を命じるなどの成果を上げていたが、巨大テック企業や民主党の献金者層からの反発を受け、トランプ政権下で更迭される見通しである。

資本集積には消費者厚生面での利点もあるため、市場支配力のみを基準とする抑制策は望ましくない。
今後は、政治過程への影響も加味した多元的な競争政策が必要である。

以上が、新自由主義を抑制するための主要方策である。
これらを執行するには、民間セクターを監督可能な強力な官僚機構の存在が不可欠である。

本記事も長くなってきたので、次回は「阿呆共鳴プラットフォーム」の殲滅方法と合わせて、より具体的な対応策を論じる。
